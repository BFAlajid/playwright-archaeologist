# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct.

Please read the full text at the link above.

## Reporting

Report violations via GitHub private security advisories on this repository, or by opening an issue marked `conduct` if the concern is not sensitive.

Maintainers are responsible for enforcement. Reports are handled confidentially.
